# 🛒 Simulador de Compras - Supermercado 

## 1. Identificação

- **Projeto:** Simulador de Compras
- **Aluno(a):** Emanuelly Montelo dos Santos
- **Trilha:** Desenvolvimento mobile

## 2. Apresentação

O Supermercado é uma loja fictícia desenvolvida
para uma atividade prática de programação.

O projeto permite simular compras de produtos de supermercado,
calcular os valores.

## 3. Produtos e preços

| Produto | Preço |
| Arroz - 5 kg | R$ 25,00 |
| Leite - 1 litro | R$ 6,00 |
| Café - 500 g | R$ 16,00 |
| Macarrão - 500 g | R$ 5,00 |


## 4. Tecnologias utilizadas

- HTML5: estrutura da página.
- CSS3: personalização visual.
- JavaScript: simulação e cálculos.
- Imagem: supermercado-tela.png.

## 5. Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo index.html em um navegador.
3. Clique em "compra".
4. Informe a quantidade desejada de cada produto.
5. Confira o resumo e o total da compra.

## 6. Captura de tela

Adicione uma captura de tela da página inicial.

Salvei a imagem na pasta do projeto com o nome
supermercado-tela.png.


## 7. Testes realizados

Registre os resultados após realizar os testes:

- Teste 1: compra de produto.
- Teste 2: compra de vários produtos.
- Teste 3: todas as quantidades iguais a zero.
- Teste 4: entrada de quantidade negativa.
- Teste 5: entrada de quantidade decimal.

## 8. Dificuldade encontrada e aprendizado

Uma dificuldade encontrada foi desenvolver a lógica
para calcular os valores dos produtos e aplicar o desconto.

Durante o desenvolvimento, aprendi a utilizar prompt()
para receber informações, Number() para converter os dados,
operações matemáticas para calcular os valores e estruturas
condicionais para verificar a aplicação do desconto.

Também aprendi a organizar um projeto utilizando
arquivos separados de HTML, CSS e JavaScript.

## 9. Utilização de inteligência artificial

A inteligência artificial foi utilizada como apoio para
compreender a estrutura do projeto, desenvolver o código
e organizar os arquivos.

O projeto foi adaptado para um supermercado fictício,
com produtos, preços e uma regra de desconto próprios.

Os resultados devem ser verificados por meio de testes
no navegador, conferindo os cálculos e as mensagens exibidas.
